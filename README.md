One original one-line dad joke, at most 140 characters:

> I named my boat 'Knot Today' because it's always anchored.

The hook is the "not today" → "knot today" homophone pun: the boat is always anchored, so the knot never gets untied. Fast, tight, groan-worthy.

## Run it

```sh
node main.ts
```

`main.ts` validates the line (1–140 characters, single line, no control characters, not only whitespace) and writes it to `/output/entry.txt`.
